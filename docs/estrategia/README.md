# Gestão estratégica da Pixel

O [Painel Executivo do Pixel HQ](pixel-hq.md) é a entrada para acompanhar prioridades, indicadores, barbearias, produtos e projetos.

O Pixel Barber é o primeiro produto da Pixel e o foco da validação comercial. O [Blueprint Estratégico v1.0](blueprint-v1.0.md) reúne a estratégia, as hipóteses de negócio e o roadmap. Sua aprovação pela direção está pendente.
